ERMES 20.0.5 is an open-source C++ finite element software that solves Maxwell's equations in the frequency domain. This document is the user manual of ERMES 20.0.5 and contains a step-by-step guide on how to install ERMES, run simulations, and visualize the results. It also describes the graphical user interface, the C++ source code, and the finite element formulations implemented in ERMES 20.0.5.

This document should be accompanied by two folders: \path{\ERMES_20.0.5}, which contains the GiD problem type user interface together with ready-to-run executables for Windows and Linux, and \path{\ERMES_CPP_20.0.5}, which contains the C++ source code. These folders also include supporting documentation, scripts, templates, and examples referenced throughout this user manual.

The complete ERMES 20.0.5 distribution is available in the GitHub repository \url{https://github.com/Ruben-Otin/ERMES-20.0.5}. Besides the two folders above, the repository contains the folder \path{Examples}, with ready-to-open GiD projects, and the folder \path{Utilities}, with tools that extend the applications of ERMES: external solvers (PETSc and Python NumPy), scripts to generate cold plasma input files from \textit{eqdsk} equilibria, scripts to import boundary conditions, current sources and element matrices from other codes, a mesh refiner, beam-tracing interfaces, and batch scripts for parametric studies and HPC clusters.

The names ERMES, ERMES 20.0, and ERMES 20.0.5 are used interchangeably throughout this manual.
